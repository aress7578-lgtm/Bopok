# 3D 건물 데이터 (시연권역)

지도 화면에서 건물을 3D로 세우기 위한 전처리 결과물입니다. 결과 파일은 `public/data/daejeon-buildings.geojson` 입니다.

> 건물 높이는 화면 표시용 추정치이며 판정 계산에는 쓰지 않음.

## 출처

- 국토교통부 **GIS건물통합정보** (브이월드 공간정보 다운로드), 대전광역시 `AL_D010_30_20261009`
- 원본 파일 날짜 2026-10-09, 데이터 기준일자 2026-10-06
- 컬럼 정의서: 국가중점데이터 컬럼정의서(배포용) — AL_D010 표
- 원본 좌표계 EPSG:5186 (Korea 2000 중부원점 2010), 건물 175,270개

## 처리 기준

| 항목 | 값 |
|---|---|
| 권역 `BBOX` (WGS84) | `[127.370, 36.360, 127.400, 36.385]` |
| 권역 거르기 | 건물 **중심점**이 권역 안이면 건물 전체를 남김 (경계에서 자르지 않음). 원본 좌표계로 변환해서 먼저 거름 |
| 작은 건물 제외 | 도형 면적(원본 좌표계, ㎡) 15㎡ 미만 (창고·부속 구조물) |
| 좌표 | WGS84, 소수점 6자리 |
| 이상값 | 층수 100 초과, `******`(자릿수 넘침), 0 은 null |

기준 상수는 `scripts/build-buildings.mjs` 맨 위에 있습니다.

## 남기는 속성

| 속성 | 뜻 |
|---|---|
| `fid` | 1부터 시작하는 짧은 숫자. 원본 id(`srcId`) 정렬 순서로 고정 |
| `srcId` | 원본 GIS건물통합식별번호 (A1, 28자리 문자열) |
| `floors` | 지상층수 (A26). 없으면 null |
| `height` | 원본 높이(m) (A16). 없으면 null |
| `h` | **지도가 읽는 최종 높이(m)**. 아래 규칙으로 계산 |
| `hSource` | `h` 를 정한 방법: `"height"` / `"floors"` / `"default"` |

용도(`use`)는 빈 값이 절반 가까이라 뺐습니다.

## 높이 `h` 계산

1. `height` 가 있으면 사용. 단, `height ÷ floors` 가 2m 미만이거나 8m 초과면 이상값으로 보고 2번으로
2. `floors × 층고`. 층고는 도시 전체에서 `height ÷ floors` 가 정상(2~8m)인 건물의 중앙값
   - 저층(1~4층): **4.00m** (표본 73,363)
   - 고층(5층 이상): **3.20m** (표본 7,069)
3. 둘 다 없으면 **6m** (약 2층)

현재 결과 (1,440동):

| hSource | 건물 수 |
|---|---|
| `height` | 735 |
| `floors` | 117 |
| `default` | 588 |

`floors` 가 있는 건물은 59.1% (851/1,440) 입니다.

## 결과 요약

- 중심점이 권역 안인 건물 1,664동 → 15㎡ 미만 224동 제외 → **1,440동**
- 파일 약 551KB, 좌표 범위 `[127.369763, 36.359891, 127.400110, 36.385618]` (건물을 통째로 남겨서 BBOX 를 조금 벗어남)

## 다시 만드는 방법

1. 원본(`AL_D010_30_20261009.shp/.shx/.dbf/.prj`)을 `data/raw/daejeon-buildings/` 에 넣습니다. (`data/raw/` 는 `.gitignore` 로 레포에 올라가지 않습니다)
2. `pnpm data:buildings`

같은 원본이면 항상 같은 결과가 나옵니다.
